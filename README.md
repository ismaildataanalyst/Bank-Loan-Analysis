##  Project Overview

This project presents a comprehensive **Bank Loan Analytics Dashboard** designed to analyze:

- Loan applications and funding performance
- Loan quality (Good vs Bad loans)
- Customer segmentation
- Loan distribution trends
- Detailed transactional insights

---

#  Key Insights

##  Critical Findings
- 13.8% loans are **bad loans (risk exposure)**
- High concentration in **debt consolidation loans**
- Higher interest rates for risky loans

---

##  Opportunities
- Improve credit risk assessment
- Target high-quality borrowers
- Optimize loan distribution strategy

---

- Improve loan approval criteria
